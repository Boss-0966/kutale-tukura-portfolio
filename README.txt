KUTALE TUKURA — PROFESSIONAL PORTFOLIO WEBSITE

FILES
- index.html: complete responsive website (HTML, CSS, and JavaScript in one file).

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in a modern browser.

BEFORE PUBLISHING
- Replace the placeholder contact email in the Contact section and in the JavaScript recipient variable.
- Add your actual CV and link to it, if you want to offer a downloadable CV.
- Replace sample project cards/links with 3–5 real artifacts from your coursework or professional work.
- Add accurate education dates, certificates, and achievements.
- Do not publish confidential case-management, student, or organizational information.
- The profile monogram is a placeholder; replace it with a professional photo only if desired and appropriate.
- The contact form uses mailto and does not store messages. For a working hosted form, connect a form service or platform feature.
- Check all links and accessibility before submission.

PUBLISHING OPTIONS
- GitHub Pages: create a repository, upload index.html, and enable Pages in repository settings.
- Netlify: drag the folder into the manual deploy area on Netlify.
- Google Sites/Wix: these platforms use their own editors; this file is a standalone HTML site and may not import as a complete editable project.
